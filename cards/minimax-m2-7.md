# MiniMax M2.7

MiniMax's flagship text model, built for agentic coding and tool use at a very low API price point.

- **URL:** https://minimaxi.com (MiniMax Agent web interface)
- **Pricing:** paid (API: ~$0.50/million tokens)
- **Platform:** web | API
- **Local-friendly:** no (closed API model)
- **Availability:** available
- **Last reviewed:** 2026-03-27

## What it does
A large language model optimized for agentic workflows — coding, spreadsheet tasks, presentations, and real-world work. Described as the first model that "deeply participated in its own evolution" during training. Benchmarks close to top closed models (Gemini 3.1 Pro, Claude Opus) on coding tasks, at ~20x lower cost. Available via MiniMax Agent (their web interface) and API.

## When to use it
High-volume agentic pipelines where cost is a constraint and you need strong coding or tool-use performance. Good drop-in for OpenClaw/Claude Code-style workflows via API.
