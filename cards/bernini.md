# Bernini (ByteDance)

ByteDance's open-source omnimodal video editor — edit any existing video with natural language, now at version 2.

- **URL:** not mentioned
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no (v2 model alone is 180GB, before VAE and text encoder)
- **Availability:** available
- **Last reviewed:** 2026-08-23

## What it does
Takes an existing video and applies natural-language edits: add or remove characters and objects, change color tone, swap backgrounds, change the camera perspective, or insert reference images (e.g. drop a specific helicopter into a scene). Version 2 released this week; version 1 saw little community uptake.

## When to use it
Reference-driven video editing if you have serious multi-GPU hardware. For most people MiniMax H3 already covers reference-to-video and is far easier to run, which is why this risks being dead on arrival.
