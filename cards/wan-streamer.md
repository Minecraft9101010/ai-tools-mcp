## What it does
Lets you talk to and direct any character in real time. Earlier versions handled portrait-shot conversations with lip sync, eye contact, and facial expressions; version 0.3 adds full-body actions and interaction with the environment (gestures, posing, looking around) on command. It splits the video into a persistent "world" (character, room, style) and an "event stream" (speech, movement, camera, user inputs).

## When to use it
Nothing to run yet. Watch for a release if you're interested in live virtual companions, VTuber-style characters, or interactive avatars that respond to voice and text in real time.
