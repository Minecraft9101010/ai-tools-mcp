## What it does
VOID (Video Object and Interaction Deletion) takes an existing video and a text prompt specifying what to remove. It deletes the object and intelligently fills in what would be behind it, accounting for physics (e.g., bowling pins stay upright if the ball is removed). Netflix's first open-source model release.

## When to use it
Removing unwanted objects, people, or watermarks from video footage while keeping the background plausible. Alternative to manual rotoscoping and inpainting workflows.
