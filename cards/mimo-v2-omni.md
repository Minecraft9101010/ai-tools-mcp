# MiMo V2 Omni

Xiaomi's multimodal model that understands and generates text, images, video, and audio — and can autonomously operate a browser.

- **URL:** https://studio.mimo.xiaomi.com (MiMo Studio)
- **Pricing:** paid (API pricing not specified)
- **Platform:** web | API
- **Local-friendly:** no
- **Availability:** available
- **Last reviewed:** 2026-03-27

## What it does
A single unified model handling text, image, video, and audio understanding and generation. Because of its vision capabilities it can analyze a screen and decide next actions — demonstrated autonomously uploading a video to TikTok including writing the description and tags. Benchmarks on par with top closed models on multimodal tasks.

## When to use it
Browser automation tasks, screen-aware agents, or multimodal pipelines where you want one model to handle vision + action without chaining separate tools.
