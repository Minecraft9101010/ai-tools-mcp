# Manim

Open-source Python library for programmatic math animations (the 3Blue1Brown engine), a good target for AI coding agents.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (Python library, renders MP4 locally)
- **Availability:** available
- **Last reviewed:** 2026-07-10

## What it does
Renders mathematical animations from code. In the video, GPT-5.6 found the GitHub repo, installed it unprompted, and produced a complex Fourier-epicycle animation drawing a butterfly, saved as MP4.

## When to use it
Math and educational animations, especially generated via a coding agent: describe the animation, let the agent write and render the Manim script.
