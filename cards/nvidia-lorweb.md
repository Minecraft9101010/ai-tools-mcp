# Nvidia LoRWeb Image Editor

Nvidia's image editor that applies a style or transformation using a before/after example pair plus a target image.

- **URL:** https://github.com/nvidia (search LoRWeb)
- **Pricing:** open-source (free)
- **Platform:** local
- **Local-friendly:** yes (open-source, run locally with GPU)
- **Availability:** available
- **Last reviewed:** 2026-03-05

## What it does
LoRWeb takes three inputs: a "before" image, an "after" image showing the desired transformation, and a target image to apply the same transformation to. It learns to mix LoRA editing modules to replicate the exact style or edit. Works for architectural sketches, Ghibli-style transfers, clay effect, comic-style conversions, and more.

## When to use it
When you have a specific edit style (before/after pair) and want to clone that exact transformation to new images. More precise than text-only style transfer for idiosyncratic transformations.
