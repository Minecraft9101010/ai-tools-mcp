# Matrix Game 3.0

Interactive world generator by Skywork AI that creates real-time 720p video that responds to keyboard/action inputs with long-term memory.

- **URL:** not mentioned (GitHub)

- **Local-friendly:** yes — 5B parameter model (~13 GB); runs on mid-to-high-tier consumer GPUs
- **Availability:** available
- **Last reviewed:** 2026-04-01

## What it does
Generates a continuous video stream that reacts to player inputs (WASD, attack, etc.) in real-time at ~40 fps, 720p. Adds long-term memory so the environment stays consistent even when the camera pans away and returns — a key improvement over earlier world generators that hallucinated inconsistent scenes.

## When to use it
Prototyping game concepts or interactive AI-generated environments. Research into AI-playable games. Generating long exploratory video sequences for creative or simulation use cases.
