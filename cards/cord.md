# CORD

Robotics framework that teaches dexterous hand skills from human demonstrations by transferring forces and torques rather than raw poses.

## What it does
Takes human manipulation demos (motion capture or plain video) and represents them as forces and torques applied to the object, then uses reinforcement learning to train a robot hand to produce the same effect even with different hand morphology. Works across object types, especially articulated objects needing multi-step manipulation.

## When to use it
Training dexterous robot hands from human video when the robot's hand doesn't match a human's; watch for the code release.
