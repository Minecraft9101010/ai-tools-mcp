## What it does
Medium-sized mixture-of-experts model purpose-built for multi-step, multi-tool autonomous work. Despite only 35B parameters it beats Kimi K2.6 and DeepSeek V4 Pro (1T+) on several benchmarks and even tops GPT 5.5 on science tests like Humanity's Last Exam, Frontier Science, Seal, and Gaia. Strong instruction following.

## When to use it
Possibly the new best agentic model you can run offline on high-end consumer hardware; the video positions it above the previous local leader Qwen 35B across the board. Pick the Q4 (21GB) build for a single 24GB GPU.
