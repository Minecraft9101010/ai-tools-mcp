# HYMT2 (Tencent)

Open-source multilingual translation models that follow detailed instructions to preserve formatting, terminology, and delimiters.

- **URL:** not mentioned (HuggingFace)

- **Local-friendly:** yes (1.8B variant is ~4GB)
- **Availability:** available
- **Last reviewed:** 2026-05-24

## What it does
Available in 1.8B, 7B, and 30B sizes. Supports 33 languages and follows translation instructions precisely, preserving JSON structure, XML tags, custom terminology, and formatting. GGUF versions available for CPU/quantized inference.

## When to use it
Translating documents, app strings, or structured data (JSON, XML) where formatting must survive the translation. Domain-specific translation needing custom terminology. Replacing cloud translation APIs for cost or privacy reasons.
