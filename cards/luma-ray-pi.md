# Luma Ray Pi

Luma AI's latest video generation model, delivering 1080p output with strong prompt adherence and style consistency.

- **URL:** https://lumalabs.ai
- **Pricing:** freemium (free tier available; paid plans for higher usage)
- **Platform:** web | API
- **Local-friendly:** no (cloud-only)
- **Availability:** available
- **Last reviewed:** 2026-03-08

## What it does
Ray Pi generates 1080p video from text prompts, emphasizing consistency across shots and accurate prompt following. Paired with Ray Modify, it allows natural-language editing of existing videos (e.g., change time of day, add weather effects, transform subjects).

## When to use it
Video generation when you need high resolution and reliable style consistency, or when you want to edit an existing clip with a text instruction rather than regenerating from scratch.
