# Articraft

Generates articulated 3D objects with moving parts and joints from text prompts.

## What it does
Uses a coding agent to write geometry and joint code for articulated 3D objects from text. Trained on a 10K-object dataset across 245 categories. Produces rigged, jointed assets rather than static meshes.

## When to use it
Rigged or jointed 3D assets for robotics training data, VR interactions, or game mechanics that require objects with movable parts.
