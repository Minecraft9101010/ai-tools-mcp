# Evoke

Fully open-source interactive world model that generates joystick-controllable video in near real time from a single image.

- **URL:** not mentioned (project page with code instructions)
- **Pricing:** open-source (Apache 2, excluding third-party code)
- **Platform:** local
- **Local-friendly:** no (final model ~57GB; needs a high-end GPU)
- **Availability:** available
- **Last reviewed:** 2026-08-23

## What it does
Takes an image plus joystick input and outputs video that responds almost instantly — driving vehicles, kayaking, scuba diving, rock climbing — with strong world understanding across artistic styles. Text prompts can inject events mid-session (volcano eruption, balloons, aurora). Only 14B parameters; generates in three steps, and sessions are designed to run for hours. All training-stage checkpoints released.

## When to use it
An open, locally runnable Genie 3 alternative for prompt-anything interactive worlds. Also a practical source of synthetic training video for robots — simulated hospital navigation, rescue scenarios, underwater exploration.
