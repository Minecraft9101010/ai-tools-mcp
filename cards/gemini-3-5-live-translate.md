# Gemini 3.5 Live Translate

Google's real-time speech translation: speak in one language and it speaks the translation in your own voice, only seconds behind.

- **URL:** Google AI Studio (free) / Gemini API / Google Translate app
- **Pricing:** free (AI Studio and Google Translate app; API usage paid)
- **Platform:** web | API | mobile
- **Local-friendly:** no (cloud service)
- **Availability:** available
- **Last reviewed:** 2026-06-14

## What it does
Continuous real-time translation that auto-detects over 70 languages and preserves the speaker's intonation, pacing, and pitch. Unlike turn-by-turn systems that wait for a speaker to finish, it generates continuously while staying a few seconds behind, keeping conversation natural. Rolled out to everyone via Google Translate on Android and iOS.

## When to use it
Live multilingual conversations: travel, cross-language meetings, calls with speakers of different languages. Better than turn-based translators when the back-and-forth needs to flow without awkward pauses.
