# SenseNova U1

Fully unified multimodal model that inputs and outputs both text and images end-to-end, using a new NeoUnifi architecture that connects pixels and words directly.

## What it does
SenseNova U1 is a reasoning model that can take text or images as input and output text and images simultaneously — not separate encoder/decoder modules, but a single unified NeoUnifi architecture. Generates complex multi-panel infographics, storyboards with interleaved text and images, and solves visual puzzles. Strong at text rendering in images, visual reasoning, and image editing via text prompts. Beats Ideogram, Qwen, and Ernie on text rendering benchmarks. Also outperforms Qwen 3.5 and Gemma 4 on visual/spatial understanding tasks.

## When to use it
When you need an AI that can reason about images and generate new images in the same conversation. Infographic generation, storyboarding, visual puzzle solving, document understanding combined with image output. The unified text+image output is the key differentiator over models that only generate one modality at a time.
