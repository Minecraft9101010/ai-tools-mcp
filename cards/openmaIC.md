# OpenMAIC

Open-source multi-agent virtual classroom platform that generates interactive AI-taught courses on any topic.

- **URL:** not mentioned (GitHub, run locally)

- **Local-friendly:** yes (designed to run locally)
- **Availability:** available
- **Last reviewed:** 2026-03-27

## What it does
Stands for Open Multi-Agent Interactive Classroom. Enter a topic, select a model, and it generates slides, quizzes, interactive simulations, and project-based learning activities — all delivered by AI teachers, with AI classmates you can chat with. Includes a whiteboard and integrates with messaging apps like Telegram via OpenClaw.

## When to use it
Self-directed learning on any topic, or setting up structured learning for kids. Replaces the need for a human tutor for many subjects.
