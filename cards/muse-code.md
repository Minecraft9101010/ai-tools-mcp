## What it does
First-party agentic coding harness for Meta's Muse Spark 1.2 model, in the same category as OpenAI Codex, Kimi Code, and Z Code.

## When to use it
Only if you've chosen Muse Spark as your model — first-party harnesses generally get the best results from their own company's model. Otherwise the model's mid-tier leaderboard standing makes the harness moot.
