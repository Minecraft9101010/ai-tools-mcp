# GPT-Policy

A robotics framework for in-context robot learning from demonstrations.

- **URL:** https://cheng-haha.github.io/GPT-Policy/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - code and local run instructions are mentioned
- **Availability:** available
- **Last reviewed:** 2026-09-20

## What it does
GPT-Policy lets a robot learn tasks from videos, images, or feedback without retraining the robot model. It uses a vision-language model to convert demonstrations into robot task behavior.

## When to use it
Use it for robotics research where a robot needs to adapt to new tasks from demonstrations or examples.
