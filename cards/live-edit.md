# Live Edit

Real-time AI video editor: stream a video in with a text prompt and it edits frames as they play, at ~13 fps.

- **URL:** not mentioned (code released, linked in video description)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (total size ~17GB, fits mid-to-high-end GPUs)
- **Availability:** available
- **Last reviewed:** 2026-07-05

## What it does
Adapts a standard video model into a causal chunk-wise streaming setup so it can edit video in small chunks without seeing the whole clip, enabling live prompt-driven edits: replacing clothing, changing weather, removing objects, restyling. Code and training script are both released.

## When to use it
Live or interactive video editing where waiting for a full offline render is not an option, or building streaming pipelines that transform video on the fly.
