# Jing Dao

A generative world simulation system with persistent world-state management.

- **URL:** https://xgenlabs.ai/research/generative-world-simulation
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - code for the Jing model is released with local run instructions, but the video model is very large
- **Availability:** limited
- **Last reviewed:** 2026-09-20

## What it does
Jing Dao separates a persistent world engine from an experience model that renders what characters see. It supports consistent environments, autonomous agents, and multiple players in the same simulated world.

## When to use it
Use it for research into persistent AI-generated worlds, multiplayer simulations, or interactive world models.
