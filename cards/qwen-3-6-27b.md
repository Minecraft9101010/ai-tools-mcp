# Qwen 3.6 27B

Currently the best medium-sized open-source model — a dense 27B parameter model with strong agentic coding, multimodal understanding, and reasoning. Only 55.6 GB.

- **URL:** https://huggingface.co/Qwen
- **Pricing:** open-source
- **Platform:** local | API
- **Local-friendly:** yes (55.6 GB; may fit on a single high-end GPU)
- **Availability:** available
- **Last reviewed:** 2026-04-26

## What it does
Qwen 3.6 27B is a dense (all 27B params active) model optimized for agentic coding, multimodal reasoning (images and video), and instruction following. Outperforms the larger Gemma 4 (which is several times bigger) on most benchmarks. Natively multimodal. The best medium-sized open-source option at the time of review.

## When to use it
When you need a capable open-source model under 60 GB that fits on high-end consumer hardware. Agentic coding tasks, multimodal understanding, or instruction-following with a model you can run locally. The sweet spot between performance and size in the open-source ecosystem.
