# LLaDA Image

LLaDA Image is an open-source image generator and editor for realistic images, posters, infographics, and image edits.

- **URL:** https://github.com/inclusionAI/LLaDA-Image
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says it has local download/run instructions and smaller FP8 variants for consumer GPUs.
- **Availability:** available
- **Last reviewed:** 2026-09-06

## What it does
It supports text-to-image generation and image editing, including changing poses, expressions, text, colors, or replacing image elements. It offers base and turbo variants, including BF16 and FP8 versions.

## When to use it
Use it when you need an open local model for both image creation and editing, especially with text-heavy or realistic outputs.
