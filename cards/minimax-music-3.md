# MiniMax Music 3

Open-source music generator, tiny enough to run on low-end GPUs, that takes a prompt (genre, tempo, key, instruments) plus lyrics with structure tags to produce clean, professional-sounding songs.

- **URL:** not mentioned (HuggingFace)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (9.8GB full model; smaller int8 version available)
- **Availability:** available
- **Last reviewed:** 2026-08-16

## What it does
Generates full songs from a descriptive prompt (genre, speed, key, instruments, vibe) plus lyrics with structural meta-tags (intro, verse, chorus, bridge, outro). Notably small for the quality delivered — the full model is under 10GB.

## When to use it
Local music generation on modest hardware when you want a complete, professional-sounding track from a prompt rather than building it stem-by-stem.
