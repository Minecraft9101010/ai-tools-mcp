# Claude Opus 4.7

Anthropic's flagship model as of April 2025, with major gains in agentic software engineering and autonomous multi-step workflows.

- **URL:** https://claude.ai | https://api.anthropic.com
- **Pricing:** paid (same pricing as Opus 4.6)
- **Platform:** web | API
- **Local-friendly:** no (cloud only)
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Handles complex long-running agentic tasks with less supervision than previous models. Significantly improved multimodal support — accepts images up to 2,500+ pixels on the long side (3x prior Claude). Ranked #1 on LM Arena for both text and coding. 1M token context window. Strong in coding, creative writing, multi-turn tasks, software IT, and literature. Notably weaker than 4.6 on business/management, hard prompts with long queries, and entertainment queries — use 4.6 for those.

## When to use it
Complex agentic coding workflows via Claude Code. Give it an entire multi-step workflow and let it run. Not the right pick if factual accuracy on niche domains or conversational performance on business/finance topics matters most.
