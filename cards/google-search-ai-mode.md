# Google Search AI Mode

Google Search rebuilt around AI agents, with monitoring, agentic booking, and in-Search code generation.

- **URL:** google.com (rolling out summer 2026)
- **Pricing:** freemium (basic free, agentic features require Pro/Ultra)
- **Platform:** web
- **Local-friendly:** no (cloud-based)
- **Availability:** limited (rolling out)
- **Last reviewed:** 2026-05-21

## What it does
Information agents monitor the web 24/7 and alert you when criteria match. Agentic booking handles pricing searches and can call businesses directly. In-Search coding generates interactive tools, graphs, and mini-apps instead of text answers.

## When to use it
Setting background alerts for specific criteria, having Google call businesses for pricing, generating interactive visualizations instead of reading text, or building persistent trackers inside Search.
