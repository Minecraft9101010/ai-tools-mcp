# Show Harness

A framework for using vision-language models to control robots through action choices.

- **URL:** https://showlab.github.io/Show-Harness/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says a GitHub repo and setup instructions are available, though a real robot is needed
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
Show Harness lets users plug in vision-language models and map their selected actions into robot-specific movement commands. The video explains that it tests whether VLMs can reason over scenes and choose meaningful robot actions.

## When to use it
Use it for robotics experiments that evaluate or repurpose vision-language models as robot controllers.
