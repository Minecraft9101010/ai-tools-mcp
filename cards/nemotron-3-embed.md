# Nemotron 3 Embed (NVIDIA)

Embedding model family for retrieval: turns text, code, and documents into vectors for search, RAG, and coding agents.

- **URL:** not mentioned (HuggingFace, linked in video description)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (8B model is 16 GB; 1B variant is 2.3 GB)
- **Availability:** available
- **Last reviewed:** 2026-07-19

## What it does
Not a chat model; it outputs numerical representations used to find similar information. The 8B model beats similarly sized embedding models like Qwen 3 and Gemma on retrieval accuracy, and all variants sit at the top of the cost-efficiency curve for their size. Multilingual, with a 1B option for smaller hardware.

## When to use it
Building search, RAG pipelines, or retrieval for coding agents locally. Pick it when you want top retrieval accuracy per dollar from a self-hosted embedding model rather than a cloud embedding API.
