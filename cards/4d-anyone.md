# 4D Anyone

Turns a single video of a person into a 4D Gaussian splat — a moving 3D character viewable from any angle.

- **URL:** not mentioned (project page with code instructions)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (model is only 12GB; fits mid to high-end GPUs)
- **Availability:** available
- **Last reviewed:** 2026-08-23

## What it does
Extracts a 3D skeleton from the source video, uses it to guide generation of many new camera views of the subject, then reconstructs everything into a 4D Gaussian splat of the character and their movements. Works across varied characters and outfits.

## When to use it
Free-viewpoint character capture from ordinary footage. Noticeably more detailed and consistent than earlier 4D approaches like ReCamMaster or TrajectoryCrafter — the current state of the art for generating 4D characters.
