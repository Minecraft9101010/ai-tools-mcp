# Arty (NVIDIA)

Real-time 3D human motion generator: text prompts and optional path/pose controls stream continuous character animation indefinitely.

- **URL:** not mentioned (GitHub, linked in video description)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (each model is ~765 MB)
- **Availability:** available
- **Last reviewed:** 2026-08-03

## What it does
Generates continuous 3D human animation in real time from a text prompt, with optional controls like paths, waypoints, key poses, or joint positions. Plans motion in two stages: overall position and trajectory first, then detailed body movement. Streaming is effectively infinite; the same output can drive a simulated humanoid robot (Unitree G1).

## When to use it
Animating game or virtual characters from text without keyframing, prototyping character movement along a specific path, or generating motion data for robot training. Also a free way to produce animation references for multimodal video models like Seedance.
