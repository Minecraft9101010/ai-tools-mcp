# Dream ID Omni

ByteDance's flexible deepfake video generator that accepts text, image, and voice reference simultaneously.

- **URL:** https://github.com/bytedance/DreamIDOmni (open source, pending)
- **Pricing:** open-source (release pending as of 2026-03)
- **Platform:** local
- **Local-friendly:** yes (open source release planned for March 2026)
- **Availability:** limited (GitHub repo exists, model weights not yet released)
- **Last reviewed:** 2026-03-05

## What it does
Dream ID Omni generates or edits video of a person using their likeness, voice, and a text prompt simultaneously. It can handle multiple characters in the same scene, swap faces and voices in existing videos, and is described as more flexible than prior methods like OV, Phantom, or LTX2.

## When to use it
Creating lip-sync or persona-driven video content where you have reference identity + voice audio. Most flexible deepfake pipeline available once open sourced.
