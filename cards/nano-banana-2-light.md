# Nano Banana 2 Light

Google's fastest and cheapest image model: ~4-second generations at roughly 3 cents per 1K image.

- **URL:** free to try via Google Flow (link in video description)
- **Pricing:** freemium (free daily allowance on Google Flow; ~$0.03 per 1K image via API)
- **Platform:** web | API
- **Local-friendly:** no (cloud model)
- **Availability:** available
- **Last reviewed:** 2026-07-05

## What it does
Lightweight variant of Nano Banana 2 designed for high-throughput workflows. Quality benchmarks slightly below the full model for both generation and editing, but it's far faster and nearly half the price. Google Flow's free tier allows several dozen images per day, resetting daily.

## When to use it
Bulk or speed-sensitive image generation where per-image cost matters more than peak quality. Use full Nano Banana 2 when quality is the priority.
