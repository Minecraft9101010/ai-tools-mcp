# Kiwi Edit

Open-source AI video editor for style transfer and object manipulation.

- **URL:** https://github.com/ (search "Kiwi Edit")
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes — open-source, runs locally; model is ~20GB so needs a higher-end GPU
- **Availability:** available
- **Last reviewed:** 2026-03-13

## What it does
Edits existing videos using text prompts or reference images — applies style transfers (sketch, cartoon, watercolor), swaps backgrounds, adds or removes objects, and changes outfits. Uses a multimodal LLM for instruction understanding combined with a video diffusion transformer. Beats open-source peers like Vase and Lucy Edit; still trails closed-source Kling 01.

## When to use it
Style-transferring footage (live-action to animated, cinematic looks), background replacement in video, reference-image-driven outfit changes. Best free local option for video editing of this kind as of March 2026.
