# Pixel Relights

Open-source tool that lets you relight a single 2D photo by dragging a cursor to move a virtual light source, including switching between flashlight and hard spotlight styles.

- **Pricing:** open-source

- **Last reviewed:** 2026-05-31

## What it does
Takes a single image, estimates a rough 3D understanding of the scene, and plugs that into Blender where the user repositions the light; that Blender-rendered lighting reference then drives the final relit prediction. Handles cluttered scenes with many objects, correctly identifying their positions from just a 2D image and relighting everything consistently as the light source moves or its harshness changes.

## When to use it
Relighting an existing photo (changing direction, warmth, or hardness of light) without needing an actual 3D scene reconstruction or reshoot.
