# Jev

A system-one decision model for fast structured decisions with calibrated confidence scores.

- **URL:** https://typesafe.ai/blog/introducing-system-one-models-and-jev
- **Pricing:** unknown
- **Platform:** API
- **Local-friendly:** no - not open source and only available through API waitlist
- **Availability:** limited
- **Last reviewed:** 2026-09-20

## What it does
Jev takes a prompt plus predefined answer options and returns confidence scores for each option instead of generating free-form text. It is designed for fast, cheap, structured software decisions rather than long-form reasoning.

## When to use it
Use it for classification, routing, decision automation, or structured choices where options are known ahead of time.
