# Occamy

An efficient open model focused on agentic benchmarks and reasoning performance.

- **URL:** https://huggingface.co/Accio-Lab/Occamy-1.0
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - model weights and GGUF versions are released
- **Availability:** available
- **Last reviewed:** 2026-09-20

## What it does
Occamy 1.0 is a post-trained Qwen 3.6 35B model with only part of the model active during use. The video says it performs strongly on agentic benchmarks and has a good intelligence-to-cost ratio.

## When to use it
Use it when you want an efficient open model for agentic workflows and can run a medium-sized local model.
