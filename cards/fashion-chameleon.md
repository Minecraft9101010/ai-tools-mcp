# Fashion Chameleon (Alibaba)

Real-time virtual try-on for video that renders garments onto a model at ~24fps on a single GPU.

## What it does
Takes a model image and one or more garment images and generates a video of the model wearing those outfits at real-time speed (~24fps on a single GPU). Multi-garment support included. Not yet publicly released.

## When to use it
Fashion e-commerce, garment visualization, or virtual model styling where you need video-format try-on rather than static images. Worth tracking for release given the real-time performance claim.
