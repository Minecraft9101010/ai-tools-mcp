# Komodo (Nvidia)

Open-source tool for generating diverse 3D human and robot motion animations from text prompts.

- **URL:** not mentioned (GitHub released, version 1.1)

- **Local-friendly:** yes

- **Last reviewed:** 2026-06-01

## What it does
Generates 3D motion sequences from text: running, jumping, stumbling, dancing, gesturing, interacting with objects. Drag-and-drop limb control for precise custom animations at specific time frames. Integrates with Nvidia Isaac Sim for robot simulation training.

## When to use it
Generating synthetic motion data for robot training, animation prototyping, or any pipeline needing labeled motion without manual mocap.
