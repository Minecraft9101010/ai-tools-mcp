## What it does
A Codex clone built around GLM: set up multiple projects as folders and let it work agentically across files, with token usage and cache-hit stats per prompt. Handles long autonomous builds (3D digital twin of Earth, code-driven promo video with TTS voiceover, Manim animations) and can install its own dependencies and self-verify with screenshots and image analysis tools.

## When to use it
The native way to run GLM 5.2 agentically if you don't already live in Claude Code or Codex. Alternatively, GLM plugs into Claude Code via ZAI's coding-helper installer and settings.json env overrides if you prefer that harness.
