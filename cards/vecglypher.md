# VecGlypher

Open-source tool that generates complete vector font families from a text description or a reference image of a few characters.

- **URL:** https://github.com (search VecGlypher)
- **Pricing:** open-source (free)
- **Platform:** local
- **Local-friendly:** yes (open-source, instructions available for local run)
- **Availability:** available
- **Last reviewed:** 2026-03-05

## What it does
VecGlypher takes either a text style description (e.g., "active, cute, loud, vintage, handwritten") or a reference image of some characters, and generates vector glyphs for the full character set plus vector outlines. Outperforms GPT-5, Gemini, and Claude on font generation benchmarks.

## When to use it
Creating a custom font or typography set when you have either a style concept in mind or a few sample characters to match. The go-to open-source option for AI font generation.
