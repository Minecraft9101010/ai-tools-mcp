# Google AI Studio (Full-Stack Mode)

Google AI Studio's expanded build environment where an AI agent autonomously generates a full-stack app — front end, back end, database, and authentication — using Firebase/Firestore.

- **URL:** https://aistudio.google.com
- **Pricing:** free (within Google AI Studio quota)
- **Platform:** web
- **Local-friendly:** no (cloud-based, locked to Firebase/Firestore backend)
- **Availability:** available
- **Last reviewed:** 2026-03-27

## What it does
In the "Build" section of AI Studio, you can prompt an agent to build a complete application. The agent handles Firebase Firestore database setup, user authentication, API integrations, and front-end code automatically — you don't need to manually configure Firebase. Demonstrated building a multiplayer location-guessing game that integrated Google Maps. Compared to Replit as a competitor.

## When to use it
Rapid full-stack prototyping when you're comfortable with Firebase as your backend. Good for solo builders or non-engineers who want a working app fast. The Firebase lock-in is the main constraint.
