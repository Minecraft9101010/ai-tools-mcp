# Sana WM (NVIDIA)

Interactive world model: image + text + keyboard inputs generate a navigable video world.

- **URL:** not mentioned
- **Pricing:** open-source (pending release)
- **Platform:** local
- **Local-friendly:** yes (distilled variant runs on RTX 5090, ~34s for a 1-min clip)
- **Availability:** unreleased
- **Last reviewed:** 2026-05-17

## What it does
2.8B parameter model that takes a starting image, text description, and keyboard inputs to produce a navigable first- or third-person video world. Maintains persistent scene memory across the session. Designed for single-GPU use.

## When to use it
Game prototyping, interactive world simulation, and real-time controllable video environments once released.
