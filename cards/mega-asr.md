# Mega ASR

Open-source speech recognition model trained specifically for noisy, real-world audio conditions.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (under 5GB)
- **Availability:** available
- **Last reviewed:** 2026-05-24

## What it does
Trained on 2.6M samples spanning 7 acoustic problem types (noise, reverb, compression, etc.). Achieves roughly 30% better accuracy than leading models on degraded audio. Model is under 5GB.

## When to use it
Transcribing noisy audio, field recordings, phone calls, or any source where Whisper struggles. Better default than Whisper when audio quality is not controlled.
