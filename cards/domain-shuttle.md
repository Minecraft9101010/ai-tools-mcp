# Domain Shuttle

Video generator built on Wan 1.2 that preserves the exact look of reference characters and objects — even mixing realistic, 2D, and 3D characters in one shot — across different art styles.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no (35GB, needs a high-end GPU)
- **Availability:** available
- **Last reviewed:** 2026-06-28

## What it does
Takes reference images/characters (including fictional or non-realistic ones) and generates consistent video output, even when transforming style (anime, holographic) or combining multiple character types — realistic, 2D, 3D — in the same scene, which competing reference-to-video models struggle with. Outperforms other reference-consistent video models on average in the source video's benchmark comparison.

## When to use it
UGC-style product/influencer video, commercials, or any workflow needing multiple distinct reference characters kept visually consistent across a generated video, when you have the GPU for a 35GB model.
