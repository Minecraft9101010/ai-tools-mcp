# GenSeption (Google DeepMind)

Turns a video model into one unified visual understanding system: depth, segmentation, tracking, camera pose, and more from a single model.

## What it does
Repurposes a standard video model into a general-purpose vision system. One model predicts depth, surface normals, camera pose, segmentation, dense pose, and 3D keypoints from an input video, beating specialist models on these tasks. The predictions can be merged to reconstruct a 4D scene and queried for scene understanding.

## When to use it
Nothing to use yet. Watch for the code release if you currently chain separate depth/tracking/segmentation models over video; this would collapse that stack into one model.
