# Mirelo Audio to MIDI

Splits a full song into separate MIDI tracks per instrument, including vocals, drums, synths, and bass.

- **URL:** not mentioned (free web demo via Mirelo's studio; GitHub for local install)
- **Pricing:** free (web demo); open-source weights under CC non-commercial license
- **Platform:** web | local
- **Local-friendly:** yes (large model is 1.4B params / 5.5 GB; small variant can run on CPU)
- **Availability:** available
- **Last reviewed:** 2026-07-19

## What it does
Upload a song and it auto-detects the instruments (voice, drums, synth, strings, bass, etc.), separates them, and generates MIDI notes for each track with roughly 80% accuracy. Three model sizes (small, medium, large); output tracks can be pulled into a DAW for cleanup.

## When to use it
Reverse-engineering an existing song's arrangement, extracting instrument parts for remixing or study, or getting a MIDI starting point you refine in a DAW. Non-commercial license on the weights, so not for commercial pipelines.
