## What it does
RealSWE evaluates whether AI agents can handle real software engineering changes in private company codebases. It focuses on understanding business requirements, existing systems, and implementation details rather than only writing code.

## When to use it
Use it to compare AI coding agents on realistic software engineering work beyond saturated public benchmarks.
