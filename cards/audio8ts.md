# Audio8TS

Super tiny text-to-speech generator — only 0.1B parameters, 1.7GB total — with multilingual voice cloning.

- **URL:** not mentioned (HuggingFace, code and models released)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (1.7GB total; fits most consumer devices)
- **Availability:** available
- **Last reviewed:** 2026-08-23

## What it does
Clones a voice from a few seconds of reference audio and reads any transcript in that voice, staying close to the original timbre. Multilingual output. The entire package (code plus models) is 1.7GB, small enough for low-end hardware.

## When to use it
Voice cloning and TTS on machines that can't run the bigger TTS models — edge devices, low-VRAM GPUs, or anywhere footprint matters more than maximum fidelity.
