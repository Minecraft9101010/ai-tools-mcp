# MiMo V2 Pro

Xiaomi's flagship foundation model built specifically for agentic tasks — 1+ trillion parameters, MoE architecture with 42B active.

- **URL:** https://studio.mimo.xiaomi.com (MiMo Studio)
- **Pricing:** paid (API pricing not specified)
- **Platform:** web | API
- **Local-friendly:** no (enterprise-scale model)
- **Availability:** available
- **Last reviewed:** 2026-03-27

## What it does
A mixture-of-experts model with over a trillion total parameters (42B active) designed for agentic coding and autonomous workflows. Benchmarks close to Claude Opus 4.6 on agentic coding tasks (PinchBench, ClawEVAL). Demonstrated vibe-coding a 3D tower defense game and full websites autonomously.

## When to use it
Agentic coding pipelines, automated software tasks, or as a backend for OpenClaw/Claude Code workflows via API. Try it in MiMo Studio for free before committing to API.
