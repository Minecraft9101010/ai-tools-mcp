# ghidra-mcp

An MCP server that lets AI agents use Ghidra for reverse engineering.

- **URL:** https://github.com/bethington/ghidra-mcp
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, it connects local Ghidra reverse-engineering workflows to AI agents
- **Availability:** available
- **Last reviewed:** 2026-10-06

## What it does
ghidra-mcp provides a set of skills that can be connected directly to an AI agent for binary analysis and reverse engineering. The video describes using it to help AI understand game internals before rewriting or modding.

## When to use it
Use it when you want an AI agent to inspect binaries through Ghidra as part of game decompilation, rewriting, or analysis.
