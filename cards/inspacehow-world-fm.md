## What it does
Generates a navigable 3D world from a photo or text prompt in real time. You can walk around and look in all directions, and the model maintains long-term spatial memory so revisiting locations stays consistent. Also supports text prompts to edit an existing scene (e.g. "European style with wooden floors"). Low latency, runs on a single consumer GPU.

## When to use it
Game prototyping, real-time VR environment generation, architectural visualization previs, or any workflow needing explorable 3D spaces from a single reference image. Quality has some edge warping but the real-time CPU-compatible generation is the key advantage.
