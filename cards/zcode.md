# Zcode

ZAI's own agentic coding harness — their equivalent of Claude Code or Codex — and currently the main way to use GLM 5.3.

- **URL:** not mentioned (subscribe to the GLM coding plan)
- **Pricing:** paid (requires GLM coding plan subscription)
- **Platform:** desktop app
- **Local-friendly:** no (cloud model behind a subscription)
- **Availability:** available
- **Last reviewed:** 2026-08-17

## What it does
Coding harness from ZAI, available on multiple platforms, similar to Codex: agents can work on multiple projects at once on your computer, call tools like MCP servers and browser extensions, and run long autonomous sessions. GLM 5.3 shows up in it once you subscribe to a coding plan.

## When to use it
When you want GLM 5.3 for agentic coding — it is not yet available via API or the ZAI online chat, so Zcode (or another coding harness with the coding plan) is the access path.
