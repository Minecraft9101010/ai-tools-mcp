# Zcode

ZAI's agentic coding harness for GLM models: a Codex-style desktop tool that works across multiple projects and files.

- **URL:** not mentioned

- **Platform:** desktop app (Mac, Windows, Linux)

- **Availability:** available
- **Last reviewed:** 2026-08-17

## What it does
A Codex clone built around GLM: set up multiple projects as folders and let it work agentically across files, with token usage and cache-hit stats per prompt. Handles long autonomous builds (3D digital twin of Earth, code-driven promo video with TTS voiceover, Manim animations) and can install its own dependencies and self-verify with screenshots and image analysis tools. As of GLM 5.3, subscribing to ZAI's coding plan is the primary access path for the latest model.

## When to use it
The native way to run GLM agentically if you don't already live in Claude Code or Codex. GLM also plugs into Claude Code via ZAI's coding-helper installer and settings.json env overrides if you prefer that harness.
