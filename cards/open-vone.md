# Open Vone

Free HuggingFace space from the GLM team that scans any open-source GitHub repo for security vulnerabilities using GLM 5.3.

- **URL:** not mentioned (HuggingFace space)
- **Pricing:** free
- **Platform:** web
- **Local-friendly:** no (hosted scanning service)
- **Availability:** available
- **Last reviewed:** 2026-08-17

## What it does
Paste a GitHub link and it queues the repo for GLM 5.3's vulnerability-hunter engine. Findings stay encrypted and go only to verified project owners, who decide whether to disclose. It has already scanned projects like LangChain and llama.cpp and surfaced critical flaws (21 vulnerabilities in one repo).

## When to use it
A free security checkup for open-source projects — especially solo maintainers or small teams who can't afford a professional audit. Submit your own repo rather than waiting for someone else to find the holes.
