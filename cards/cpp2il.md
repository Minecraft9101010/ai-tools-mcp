# Cpp2IL

A Unity game decompilation tool for extracting information from IL2CPP-based games.

- **URL:** https://github.com/SamboyCoding/Cpp2IL
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, it is a local GitHub tool for Unity game analysis
- **Availability:** available
- **Last reviewed:** 2026-10-06

## What it does
Cpp2IL is presented as the Unity-focused tool to use alongside AI agents for decompiling Unity games. The video groups it with ILSpy as a tool for game rewrite workflows.

## When to use it
Use it when analyzing or decompiling Unity games, especially IL2CPP-based titles, as part of an AI-assisted modding workflow.
