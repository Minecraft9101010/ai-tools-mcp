# Numina

Model-agnostic video generation add-on that corrects object count errors from any base video model.

- **URL:** not mentioned (GitHub released)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Plugs into any open-source video model (e.g., Wan 1.2.1, Wan 1.2.2) and enforces prompt-specified object counts during generation. Base models frequently generate wrong numbers of people, animals, or objects; Numina fixes this without retraining the base model.

## When to use it
Any video generation workflow where the count of specific objects in the scene matters.
