# Intern Lumina U2

Intern Lumina U2 is an open-source multimodal image generator, image editor, and vision-capable language model.

- **URL:** https://internlm.github.io/InternLumina-U2/
- **Pricing:** open-source
- **Platform:** local, web
- **Local-friendly:** unknown, the transcript says local instructions are posted but the model upload to Hugging Face was still pending.
- **Availability:** limited
- **Last reviewed:** 2026-09-06

## What it does
It can generate and edit images while also analyzing visual inputs such as medical scans, paintings, and diagrams. The host describes it as a diffusion large language model with strong world and prompt understanding.

## When to use it
Use it for multimodal image generation, precise image edits, and visual question answering once the model files are available.
