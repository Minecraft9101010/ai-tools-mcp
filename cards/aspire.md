# Aspire

Self-improving robotics system that turns failed robot attempts into a growing library of reusable skills, like agent skills for coding assistants applied to robots.

## What it does
Writes robot control programs as code, executes them, watches the outcome, repairs the code on failure, validates the fix, and saves it into a skill library so the mistake isn't repeated. Three pieces: a closed-loop execution engine, a growing skill library, and an evolutionary search over candidate programs. A self-improving loop rather than one policy per task.

## When to use it
Robot learning research where repeated failures should compound into knowledge instead of being discarded. Watch for the code release before planning around it.
