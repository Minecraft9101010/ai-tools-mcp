# Telestyle V2

Style transfer that works in every direction: apply any reference image's style to any content image, artistic-to-artistic included.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (based on Qwen Image Edit; mid-to-high-end consumer GPU, despite being tested on an H100)
- **Availability:** available
- **Last reviewed:** 2026-06-21

## What it does
Transfers the style of a reference image (painting, watercolor chibi, any art style) onto a new image. Unlike older style-transfer tools that only handle realistic-content-plus-artistic-style pairs, it handles all combinations, including restyling an already-stylized image into yet another style.

## When to use it
Converting photos or artwork into a specific art style from a single reference, or chaining style conversions. Runs locally on consumer hardware via its Qwen Image Edit base.
