# Isaac 0.5

An open-source robot foundation model for vision, language, state understanding, and action prediction.

- **URL:** https://www.perceptron.inc/blog/introducing-isaac-0-5
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the model is open-sourced with download and run instructions
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
Isaac 0.5 takes images, video, language instructions, robot state, and previous actions to predict robot actions or answer questions. It is trained across many robot systems for transfer across robot types.

## When to use it
Use it for robotics research requiring a general robot foundation model for perception, reasoning, and action generation.
