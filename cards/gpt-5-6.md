# GPT-5.6

OpenAI's latest frontier family (Soul, Terra, Luna): one-shot agentic coding with minimal hand-holding, at less than half Claude Fable 5's price.

- **URL:** https://chatgpt.com (also via API and the free Codex/ChatGPT desktop app)
- **Pricing:** paid (paid plans on ChatGPT; free users get the mid-tier Terra model in Codex/ChatGPT Work; API available)
- **Platform:** web | API | desktop app
- **Local-friendly:** no (cloud-only)
- **Availability:** available
- **Last reviewed:** 2026-07-10

## What it does
Three sizes: Soul (largest), Terra (mid), Luna (fast), each with effort levels up to Ultra. Built for long-horizon agentic work; it one-shots complex builds (a voice-chat anime avatar app, a from-scratch fluid sim with webcam hand tracking) that other models need corrections on. Tops Agent's Last Exam, Deep We (rank #1, within Fable 5's confidence interval but far cheaper), Arc-AGI-2 (92.5%) and Live Bench; sits one point behind Fable 5 on Artificial Analysis at under half the price. Weaknesses: very slow at Ultra effort (10-30 min per task), high Omniscience hallucination rate (89% vs Fable's 55%, GLM 5.2's 28%), failed medical scan identification and the hidden-frog vision test.

## When to use it
The cost-efficient frontier pick for agentic coding and long autonomous tasks; also the best frontier option for biology/cybersecurity work since it answers what Claude Fable refuses. Avoid when hallucination risk matters most or when you need fast interactive turnaround at max effort.
