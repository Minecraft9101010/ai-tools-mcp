# UniMesh

3D model generator and editor that takes text or image input, generates 3D models, and edits them with text prompts (change color, add objects, modify materials).

## What it does
UniMesh generates 3D models from text descriptions or images and supports bidirectional editing: you can modify generated models with text prompts (make the astronaut hold the moon, add wheels to the bulldozer, change the motorcycle color) or describe an existing 3D object to get a text caption (option captioning). Handles a wide variety of object types.

## When to use it
Generating 3D assets from concept descriptions or reference images. Iterative 3D design where you generate and then refine via natural language. Captioning or describing 3D objects in existing asset libraries.
