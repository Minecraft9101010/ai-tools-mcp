# Stable Layers (Stability AI)

Teased tool that splits a flat image into separate transparent layers using reinforcement learning instead of hard-to-collect paired training data.

## What it does
Breaks an image into separate transparent layers that recombine into the original when merged. Skips the usual need for paired (final image + ground-truth layers) training data by scoring its own generations with a vision-language model and improving through reinforcement learning. Outperforms Qwen Image Layered on layer separation, error rate, alpha mask cleanliness, and occlusion handling in Stability's own comparison.

## When to use it
Not yet — watch for release. Once available, useful for converting a flat image into an editable, Photoshop-style layered file.
