## What it does
Unlike most 3D generators that either focus on appearance or only handle one object type (e.g., rigid bodies), PhysX Omni generates objects with geometry, scale, material properties, and motion/joint understanding in one framework — a generated car has wheels that actually roll, a generated object has joints in the correct places that move realistically. Outperforms competing models (Articulate Anything, PhysX Gen, PhysX Anything) across benchmarks. Code, training scripts, and training dataset are released.

## When to use it
Generating game or simulation assets that need to actually move and interact with physics, not just look correct as a static render.
