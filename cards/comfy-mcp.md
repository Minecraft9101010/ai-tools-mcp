# ComfyMCP

Official MCP bridge that lets AI agents build, edit, and run ComfyUI workflows from natural language, no node-wrangling required.

- **URL:** not mentioned (docs linked from announcement)
- **Pricing:** free (public beta)
- **Platform:** local (works with any agentic platform via MCP)
- **Local-friendly:** yes (drives a local ComfyUI install)
- **Availability:** available
- **Last reviewed:** 2026-07-05

## What it does
Connects an AI agent to ComfyUI so it can search models, nodes, and templates, assemble workflows, download what's needed, and run everything autonomously from a plain-language prompt. Comfy auto-updates best-practice workflows on their end, so the agent isn't working from stale patterns.

## When to use it
Running open-source image/video/audio models locally without learning ComfyUI's node graph, or letting an agent execute multi-step generation workflows unattended. Big productivity lift for existing ComfyUI power users too.
