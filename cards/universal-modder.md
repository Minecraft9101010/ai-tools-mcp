# Universal Modder

A GitHub project that provides AI-agent skills for game modding and mashups between games.

- **URL:** https://github.com/rehan-remade/universal-modder
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, it is provided as a GitHub repository intended to be used with local game files and AI agents
- **Availability:** available
- **Last reviewed:** 2026-10-06

## What it does
Universal Modder includes a mashup feature and instructions for AI agents to integrate or transfer content between games. The video describes using it for end-to-end game integration and mechanic/content transfer.

## When to use it
Use it when you want to experiment with AI-assisted game mashups, pass-through mods, or transferring mechanics and assets between games you own.
