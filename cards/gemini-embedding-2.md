# Gemini Embedding 2

Google's first natively multimodal embedding model, available via API.

- **URL:** https://ai.google.dev/
- **Pricing:** paid (API)
- **Platform:** API
- **Local-friendly:** no — cloud API only
- **Availability:** available
- **Last reviewed:** 2026-03-20

## What it does
Converts text, images, video, audio, and documents into a shared embedding space — meaning you can do cross-modal similarity search (find an image inside a document, find an audio clip in a video, etc.). Supports 8,000+ token context for text, up to 6 images per request, 120 seconds of video/audio, and PDFs up to 6 pages. Supports 100+ languages.

## When to use it
Building multimodal RAG pipelines, cross-modal search (find images by audio description, find audio clips in video), or any application that needs to compare or retrieve across mixed content types.
