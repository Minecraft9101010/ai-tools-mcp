# Moonlink 3D Agent

Agentic system that operates directly inside Blender to build, edit, and iterate on 3D scenes — treating 3D work as a long-horizon agent loop rather than a one-shot generation.

## What it does
Moonlink's 3D world-building agent operates inside Blender: takes a goal or instruction (plus optional reference images), clicks around the interface, edits objects, adjusts lighting, and iterates like a human would. Runs long sequences of actions in a loop — build, check, fix, repeat — optimizing for scene quality, reference consistency, and structural correctness (proper object connections, working animations, correct states). Can learn workflows from expert demonstrations and reuse those patterns on future projects. Covers articulated objects (cabinets, hinges, appliances) and full environments (malls, factory floors, outdoor scenes).

## When to use it
3D production workflows in Blender where repetitive scene-building, object placement, or lighting setup consumes significant time. Agents who need to handle entire chunks of a 3D production pipeline autonomously. Early-stage teams building towards AI-driven game or film asset pipelines.
