# Wave TTS (ByteDance)

Open-source zero-shot voice cloning TTS, built on F5 TTS, that clones a voice from a few seconds of audio and speaks any transcript.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (checkpoint ~10GB)
- **Availability:** available
- **Last reviewed:** 2026-06-07

## What it does
Clones a voice from roughly 3-4 seconds of reference audio and generates new speech from a text transcript in that voice. Built on top of F5 TTS. Training and fine-tuning scripts are included alongside inference code.

## When to use it
Local voice cloning/dubbing projects where you want a fast, open-source option built on an already-proven TTS base (F5 TTS) rather than a cloud voice-cloning service.
