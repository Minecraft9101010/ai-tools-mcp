# Qwen 3.5

Alibaba's open-source frontier model family matching top closed models, with consumer-runnable quantized variants.

- **URL:** https://huggingface.co/Qwen
- **Pricing:** open-source (free to download and run)
- **Platform:** local | API
- **Local-friendly:** yes (27B FP8 = 31GB; quantized 27B via Unsloth = 10GB, needs ~12GB VRAM)
- **Availability:** available
- **Last reviewed:** 2026-03-05

## What it does
Qwen 3.5 is Alibaba's most intelligent open-source model as of March 2026, competitive with GPT-5.2, Claude, and Gemini on standard benchmarks. Available in 27B, 35B, and 122B sizes. Smaller quantized versions from Unsloth can run on a 12GB VRAM consumer GPU.

## When to use it
Running a frontier-quality open-source model locally for privacy or cost reasons. The 27B quantized variants are practical on high-end consumer hardware. Also used as a base for fine-tuning and downstream models like Physic Edit.
