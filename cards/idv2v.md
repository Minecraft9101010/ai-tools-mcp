# IDV2V (Netflix)

Open-source video style transfer that restyles an entire clip from a single edited keyframe, while preserving character identity and motion exactly.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no (main model ~80GB, needs high-end consumer hardware)
- **Availability:** available
- **Last reviewed:** 2026-08-02

## What it does
Plug in an existing video, edit one keyframe to show the desired new look (background, lighting, clothing, overall style), and the system spreads that style across the entire clip while keeping the character's face, expressions, and movement identical to the original. Generates up to 720p.

## When to use it
Restyling existing footage (lighting, wardrobe, aesthetic) without re-shooting or re-animating, when you have the GPU headroom for an 80GB model — expect more compressed versions later.
