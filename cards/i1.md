# I1 (Princeton)

Fully open-source image model from Princeton: not the best generator, but the whole training recipe, data pipeline, and code are published.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (3B parameters, ~12GB)
- **Availability:** available
- **Last reviewed:** 2026-06-14

## What it does
Generates photorealistic images, art styles, anime, and strong text rendering, but honestly trails Z Image, Qwen Image, and likely Ideogram and Ernie Image. Its value is transparency: models, training and inference code, dataset links, and the data processing pipeline are all released, where leading open models publish only weights.

## When to use it
Studying how to train an image model from scratch, including dataset formatting and data pipelines. Not the pick for actually generating images; use Z Image or Qwen Image for that.
