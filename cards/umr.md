# UMR

A unified motion retargeting system for translating human motions into robot-compatible movements.

- **URL:** https://hanyang9.github.io/UMR
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says code and local setup instructions are released
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
UMR maps human body motion to robot bodies while respecting robot proportions, joints, and constraints. It helps preserve contacts with objects and the environment during retargeted motions.

## When to use it
Use it for robotics research where human motion capture needs to be transferred to humanoid or other robot bodies.
