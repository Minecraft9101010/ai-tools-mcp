# LTX Director

Community node that turns ComfyUI into a mini video editor for LTX generations — combine workflows and stitch multiple clips together.

- **URL:** not mentioned (GitHub repo by What Dreams Cost)
- **Pricing:** open-source
- **Platform:** local (ComfyUI)
- **Local-friendly:** yes (runs wherever LTX runs)
- **Availability:** available
- **Last reviewed:** 2026-08-18

## What it does
A ComfyUI node that lets you mix text-to-video, image-to-video, first-frame/last-frame, and custom audio in one place, generate multiple clips, and stitch them into a single video. Originally built for LTX 2.3 but also works with LTX 2.5.

## When to use it
Multi-shot LTX projects where you'd otherwise export clips and assemble them in an external editor. Technical to set up; the GitHub repo carries the instructions.
