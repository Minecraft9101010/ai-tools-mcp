# HY World 2.0 (Tencent)

Tencent's multimodal world model that generates, reconstructs, and simulates interactive 3D worlds from text, image, or video input.

- **URL:** https://github.com (partial code released; remaining models coming)
- **Pricing:** open-source (partial, more coming)
- **Platform:** local
- **Local-friendly:** unknown (GPU requirements not specified)
- **Availability:** limited (partial open-source; full release pending)
- **Last reviewed:** 2026-06-01

## What it does
Accepts text prompts, single images, multiple images, or video and generates complete interactive 3D scenes you can explore and control. Outputs are pipeline-ready: exports mesh, 3DGS, and point cloud formats compatible with Unity or Unreal. First-person and third-person views supported. Suitable for robot training environments.

## When to use it
3D world creation that needs to integrate into existing game engines or simulation frameworks. More production-ready output format than most alternatives.
