## What it does
Arrow-1 generates SVG vector graphics from text prompts or reference images. It draws paths sequentially using mathematical equations rather than pixels, so output scales to any resolution. Tops the SVG Arena leaderboard above GPT-5, Gemini, and Claude for this specific task.

## When to use it
Logo design, icon creation, or any output you need to scale without quality loss. Better than general-purpose LLMs for pure SVG quality. Can also vectorize an uploaded raster image.
