# Nano Banana (Google Imagen 4 Pro)

Google's leading image generation model, second only to GPT Image 2 in most benchmark comparisons as of April 2025.

- **URL:** https://gemini.google.com (and via API)
- **Pricing:** freemium
- **Platform:** web | API
- **Local-friendly:** no (cloud only)
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Text-to-image and image editing model from Google. Includes an optional web search mode for more grounded generations. Good at photorealistic images but struggles with accurate text rendering, complex multi-element grids, and spatial reasoning compared to GPT Image 2. Outperforms GPT Image 2 on spatial/floor-plan tasks.

## When to use it
Decent fallback when GPT Image 2 is unavailable or rate-limited. Better than GPT Image 2 specifically for tasks requiring spatial layout understanding from a floor plan or similar reference.
