# Flux 3 (Black Forest Labs)

Unified multimodal model spanning image, video with audio, and even robotics action prediction; currently preview-only.

- **URL:** not mentioned (early access request link in video description)
- **Pricing:** unknown (full/max model will be paid API; a lower-quality dev version planned as open weights)
- **Platform:** API (planned); local for the future dev version
- **Local-friendly:** unknown (dev open-weights version announced, not out)
- **Availability:** limited (preview; early access by request)
- **Last reviewed:** 2026-07-26

## What it does
One model covering text-to-video, image-to-video, reference inputs, video-to-video editing by natural language, and image generation, with audio built into videos (up to 20 seconds, shown at 720p) and strong typography. Self-reported preference tests put it slightly ahead of Gemini Omni Flash and Seedance 2.0, but the preview clips don't look close to Seedance quality on prompt/physics understanding and action.

## When to use it
Nothing to use yet beyond requesting early access. Watch for the open-weights dev release if you want a local video+audio model; treat the benchmark claims skeptically until independent tests land.
