# Lance (ByteDance)

Open-source unified multimodal model for text-to-video, video editing, text-to-image, image editing, and visual Q&A.

- **URL:** not mentioned (GitHub)

- **Availability:** available
- **Last reviewed:** 2026-05-24

## What it does
A 3B parameter model that handles image generation, image editing, video generation, multi-turn video editing (background replacement, style changes, object edits), and visual Q&A in a single unified model. Replaces several specialized tools with one.

## When to use it
Single model for combined image and video generation/editing workloads, multi-turn iterative video edits, or visual Q&A over video content. Best suited for setups with 40GB+ VRAM.
