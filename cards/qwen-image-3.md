# Qwen Image 3 (Alibaba)

Alibaba's best image model: dense text-heavy generations (down to 10px text), image editing, and strong world knowledge; closed for now.

- **Availability:** available
- **Last reviewed:** 2026-07-26

## What it does
Generates images jam-packed with accurate text, math equations, icons, and UI layouts (fake VS Code screenshots, scientific-paper pages), plus photorealistic work with micro-details like pores and hair strands. Also edits existing images with world understanding: turning a photo into a labeled infographic, restoring damaged photos, annotating images. Supports 12 languages and text rendering as small as 10 pixels.

## When to use it
Text-dense or multilingual image work in the Qwen ecosystem. Against other closed models it lands near GPT Image and Seedream rather than above them, so it's not a reason to switch if you already use those.
