# ComfyUI

The most popular node-based interface for running open-source image and video generators locally.

- **URL:** https://github.com/comfyanonymous/ComfyUI
- **Pricing:** free / open-source
- **Platform:** local
- **Local-friendly:** yes (dynamic VRAM allocation allows running larger models than expected)
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Node-graph workflow interface for running and chaining open-source AI image/video models locally. Supports GGUF-compressed models via the ComfyUI-GGUF extension (by City96), auto-downloads missing models with a click, and dynamically allocates memory so you can run models that would otherwise exceed your VRAM. Has built-in templates for models like Ernie Image Turbo. Results auto-save to an output folder.

## When to use it
Any time you're running open-source image or video models locally. The standard interface for the open-source AI image generation ecosystem. Handles model downloads, GGUF loading, workflow management, and browser preview.
