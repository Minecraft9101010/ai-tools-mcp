# Nimble

An open-source adapter model that mimics Jev-style structured decision scoring.

- **URL:** https://huggingface.co/bespokelabs/Bespoke-Nimble-9B
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - available on Hugging Face with download/run instructions, but requires the Qwen base model
- **Availability:** available
- **Last reviewed:** 2026-09-20

## What it does
Nimble takes a text prompt and a set of options, then returns confidence scores for each option. It is a LoRA adapter trained on top of Qwen 3.5 9B.

## When to use it
Use it if you want an open-source Jev-like model and can run the required Qwen base model locally.
