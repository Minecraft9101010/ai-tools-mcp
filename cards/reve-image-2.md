# Reve Image 2 (Reve AI)

Layout-first image generator that builds a structured JSON scene layout — bounding boxes, z-index, per-object description — before rendering, giving precise control over composition.

## What it does
Instead of generating directly from a text prompt, it lays the image out as a structured, code-like format with bounding boxes for each element first, then renders the final image from that layout — so individual elements (a bowl, a cutting board, a plate of pasta) can be edited afterward while the rest of the image stays intact. Ranked #2 on the Arena text-to-image leaderboard behind GPT Image 2, ahead of Nano Banana 2.

## When to use it
Compositions needing explicit control over where each element sits — posters, infographics, multi-object scenes — where you want to edit one region without regenerating the whole image.
