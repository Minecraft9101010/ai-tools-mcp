# Sakana Fugu

Paid orchestrator that routes prompts across multiple closed and open models and combines their outputs — marketed with benchmark claims that blur "beats Claude/GPT" with "an ensemble of models beats a single model."

- **URL:** not mentioned
- **Pricing:** paid (described as expensive in the source video)
- **Platform:** API
- **Local-friendly:** no
- **Availability:** available
- **Last reviewed:** 2026-06-28

## What it does
Routes a prompt to different closed and open models and coordinates their outputs — not a base language model itself. Sakana claims it surpasses Claude and GPT frontier models across knowledge, reasoning, and agentic coding benchmarks, but doesn't disclose which models it uses or how work is allocated, and the "beats frontier models" framing is misleading since ensembling multiple different models typically outperforms any single one anyway.

## When to use it
Treat the benchmark claims skeptically — it's an opaque, expensive router rather than a comparable single model. Only consider it if the black-box routing and cost are acceptable trade-offs.
