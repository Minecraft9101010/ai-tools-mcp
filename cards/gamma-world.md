## What it does
Most interactive world models handle only one controllable viewpoint. Gamma World generates real-time video (24fps) for scenes with 2 to 4 independent agents simultaneously, using a "simplex rotary agent encoding" to give each agent a distinct identity/control signal without locking the system to a fixed player count. Training scripts and a data-prep tool are planned for release alongside the code.

## When to use it
