# Meridian

An open-source video model from Viggle for changing camera angle and timing in existing videos.

- **URL:** https://huggingface.co/Viggle/Meridian
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - released on Hugging Face with local install/run instructions, though the base model is large
- **Availability:** available
- **Last reviewed:** 2026-09-20

## What it does
Meridian reconstructs a rough 3D representation of an input video scene and regenerates it from a new camera path. It can create orbit, pan, distance-change, and bullet-time style effects.

## When to use it
Use it when you want to reframe or reshoot an existing video from a different camera perspective.
