# World Sculpt

An AI system that reconstructs editable object-level 3D scenes from images or video.

- **URL:** https://alaya-lab.github.io/WorldSculpt/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says code and run instructions are available
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
World Sculpt turns multiple images or video of a scene into a 3D scene with separate editable objects. It can also convert Gaussian splat worlds into 3D mesh scenes.

## When to use it
Use it when you need object-level 3D reconstruction that can be edited, rearranged, or converted into mesh assets.
