# Marlin 2B

Open-source video language model that extracts structured, timestamped information from video.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (under 6GB)
- **Availability:** available
- **Last reviewed:** 2026-05-24

## What it does
2B parameter model based on Qwen 3.5. Produces scene descriptions, timestamped event logs, and supports event search queries over long video. Turns unstructured video into structured, searchable data.

## When to use it
Video search and moderation, surveillance footage review, dataset labeling, or any workflow that needs to convert long video into timestamped structured output without cloud APIs.
