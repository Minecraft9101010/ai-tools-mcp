## What it does
OpenGame takes a game concept and runs through an autonomous agent workflow: classification, scaffolding, design, asset synthesis, implementation, and verification — all in a self-correction loop. Maintains a Game Skill library of successful tasks and templates, plus a Debug Skill database of encountered errors and verified fixes. Produces playable games with well-designed assets and mechanics. Outperforms prompting state-of-the-art LLMs directly on end-to-end game creation.

## When to use it
Rapid prototyping of small games without a developer. Generating game templates as starting points for further development. Studying agentic code generation on structured, testable creative tasks.
