# Motion for Motion

Transfers movement from one video to a completely different character or scene, no skeletons or ControlNet required.

## What it does
Tracks points across a source video to build a motion flow map, matches those points to the target, and injects the new positions into a video model. Works across characters with completely different body proportions (e.g., fox motion onto a giraffe) and handles dancing and varied environments.

## When to use it
Nothing to use yet. Watch for a code release if you need skeleton-free motion transfer between mismatched characters, which existing ControlNet/skeleton pipelines handle poorly.
