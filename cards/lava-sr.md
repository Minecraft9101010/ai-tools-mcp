# Lava SR

Extremely lightweight audio enhancement model that runs real-time on CPU or mobile.

- **URL:** https://huggingface.co/spaces (search Lava SR)
- **Pricing:** free (Hugging Face Space; also runnable locally)
- **Platform:** web | local
- **Local-friendly:** yes (50MB model size; runs 5,000x real-time on GPU, 60x on CPU)
- **Availability:** available
- **Last reviewed:** 2026-03-05

## What it does
Lava SR cleans up noisy or messy audio in effectively real-time. The model is only 50MB, runs on a standard CPU or mobile phone, and processes audio ~5,000x faster than real-time on a GPU. Accessible via Hugging Face Space or Google Colab, and can be run locally.

## When to use it
Quickly cleaning up voice recordings, old audio, or low-quality clips before transcription or publishing. Best lightweight option when you don't want a heavy audio processing pipeline.
