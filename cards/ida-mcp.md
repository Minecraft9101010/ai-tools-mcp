# ida-mcp

An MCP integration that lets AI agents use IDA for reverse engineering.

- **URL:** https://github.com/HexRaysSA/ida-mcp
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, it is a local MCP integration for IDA workflows
- **Availability:** available
- **Last reviewed:** 2026-10-06

## What it does
ida-mcp provides an AI-agent-accessible MCP for reverse engineering with IDA. The video mentions it as a similar option to the Ghidra MCP.

## When to use it
Use it when your reverse-engineering workflow is based on IDA and you want an AI agent to access those capabilities.
