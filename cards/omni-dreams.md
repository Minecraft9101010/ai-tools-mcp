# Omni Dreams (NVIDIA)

Real-time generative world model for autonomous driving simulation — turns a starting frame, prompt, map, and trajectory into a photorealistic multi-camera driving video.

## What it does
Generates photorealistic multi-camera driving footage that reacts to a car's actions, using a starting frame, text prompt, map data, and trajectory as input. Can render extreme weather, edit existing footage (remove/add objects, change vehicle colors), and reconstruct footage that matches a given map plus planned trajectory.

## When to use it
Generating synthetic training/simulation video for autonomous driving models when real-world driving data is scarce for a given scenario.
