# Mistral Medium 3.5

Mistral's dense 128B parameter open-source model — underperforms on independent leaderboards despite strong in-house benchmark claims, and expensive via API.

- **URL:** https://mistral.ai
- **Pricing:** open-source (free to download) | paid API (expensive relative to comparable open-source alternatives)
- **Platform:** local | API
- **Local-friendly:** yes (128B dense; large but downloadable)
- **Availability:** available
- **Last reviewed:** 2026-05-03

## What it does
Mistral Medium 3.5 is a dense 128B parameter model with 256K context. In-house benchmarks show competitive agentic and reasoning scores, but independent Artificial Analysis rankings show significantly worse performance than DeepSeek V4 and other open-source models. The API is more expensive than Kimi K 2.6 and DeepSeek. Context window (256K) is 4x smaller than the 1M token leaders.

## When to use it
Primarily if EU data residency regulations require a European AI provider. Otherwise, better open-source alternatives exist at lower cost (Kimi K 2.6, DeepSeek V4) with stronger independent benchmark performance.
