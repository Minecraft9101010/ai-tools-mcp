# Gmail Live / Docs Live / Keep Voice

Voice-powered AI across Gmail, Docs, and Keep for hands-free interaction with Workspace.

- **URL:** gmail.com, docs.google.com, keep.google.com
- **Pricing:** paid (Pro/Ultra and business)
- **Platform:** web
- **Local-friendly:** no (cloud-based)
- **Availability:** limited (rolling out summer 2026)
- **Last reviewed:** 2026-05-21

## What it does
Gmail Live lets you ask inbox questions aloud. Docs Live converts rambling spoken input into structured drafts. Keep Voice turns voice notes into organized, searchable notes.

## When to use it
Drafting docs while moving, capturing ideas without typing, pulling inbox information hands-free, or turning spoken thoughts into structured Docs without cleanup work.
