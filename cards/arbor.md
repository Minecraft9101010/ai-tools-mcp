# Arbor

Open-source system that turns AI agents into cumulative researchers: a living hypothesis tree where experiments build on saved evidence instead of being forgotten.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source (Apache 2)
- **Platform:** local
- **Local-friendly:** unknown (harness; underlying model requirements depend on the model used)
- **Availability:** available
- **Last reviewed:** 2026-06-14

## What it does
Breaks a research objective into hypotheses via hypothesis tree refinement: a coordinator manages overall strategy while executor agents test individual ideas in isolated instances and report back, with each tree node tracking a hypothesis and its evidence. Outperforms standard harnesses like Claude Code and Codex on optimizer design, architecture design, agentic coding, and math reasoning, with some significant gains.

## When to use it
Autonomous or semi-autonomous research where agents normally lose the big picture: iterating on ML architectures, optimizer design, or any experiment loop that needs persistent memory of what was tried and learned. Apache 2, commercial use allowed.
