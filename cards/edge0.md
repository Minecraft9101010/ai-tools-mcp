# Edge0

A framework for running mixture-of-experts language models on memory-constrained edge devices.

- **URL:** https://github.com/Edge0-AI/edge0/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, it is specifically designed to reduce memory requirements and run locally on Mac or edge devices
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
Edge0 streams only the active experts needed for a query instead of loading an entire MoE model into memory. The video says it can run a 35B model with as low as 2.9 GB of memory in the demonstrated setup.

## When to use it
Use it when you want to run MoE models locally on devices with limited RAM or memory.
