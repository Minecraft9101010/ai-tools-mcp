# Generative World Renderer

AI tool that reskins AAA video game footage into entirely different visual styles using a text prompt.

- **URL:** not mentioned
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes — code released on GitHub; requires Nvidia Cosmos Transfer (7B, ~29 GB) plus Wan 2.1 (~3 GB); high-end GPU needed
- **Availability:** available
- **Last reviewed:** 2026-04-05

## What it does
Reads G-buffer data (depth, normals, albedo, metallic/roughness) from real AAA game footage, then uses a video diffusion model to restyle the scene with a text prompt. Lets you change environment, lighting, weather effects, or art style while preserving original geometry and motion. Demonstrated on Black Myth: Wukong footage.

## When to use it
Game developers or artists who want to prototype visual styles or create concept videos from existing gameplay without re-rendering. Also useful for creating stylized game trailers.
