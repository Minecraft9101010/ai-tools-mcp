# Marigold v2

An AI model for estimating depth, surface normals, albedo, and other 3D structure maps from a regular image.

- **URL:** https://huggingface.co/spaces/huawei-bayerlab/marigold-v2-web
- **Pricing:** open-source
- **Platform:** web, local
- **Local-friendly:** yes, the transcript says code and local setup instructions are provided, though high-resolution inference needs 17-29 GB VRAM
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
Marigold v2 converts images into detailed pixel-level geometry-related maps such as depth maps and surface normals. The video highlights that it is higher resolution and more accurate than previous comparable methods.

## When to use it
Use it when you need depth or surface-normal estimation from 2D images for 3D, VFX, vision, or graphics workflows.
