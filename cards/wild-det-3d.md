# Wild Det 3D

Lightweight real-time 3D object detection model that runs on an iPhone and draws accurate 3D bounding boxes with metric depth.

- **URL:** not mentioned (GitHub/HuggingFace released)
- **Pricing:** open-source
- **Platform:** local | mobile
- **Local-friendly:** yes (runs on iPhone in real time)
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Draw a box around any object in a live scene and it tracks it in 3D with accurate bounding boxes, metric depth, and dimensions. Also accepts text prompts to auto-detect object categories across images and video. Maintains 3D tracking even as objects move through space.

## When to use it
Augmented reality, robotics, or spatial AI applications where you need 3D object detection on lightweight/mobile hardware without a server call.
