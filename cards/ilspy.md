# ILSpy

A .NET decompiler used to inspect and decompile .NET applications and games.

- **URL:** https://github.com/icsharpcode/ilspy
- **Pricing:** open-source
- **Platform:** local, desktop app
- **Local-friendly:** yes, it is a local decompiler for .NET applications
- **Availability:** available
- **Last reviewed:** 2026-10-06

## What it does
ILSpy helps decompile .NET applications, including some games. The video suggests pointing AI agents to it for .NET-based game decompilation.

## When to use it
Use it for AI-assisted analysis or rewriting of .NET games and applications you own.
