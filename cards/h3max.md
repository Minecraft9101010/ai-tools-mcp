# H3Max (Stability AI)

Stability AI's speed-optimized MiniMax H3 fine-tune that finishes video generations within seconds — currently behind a paid, closed API.

- **URL:** not mentioned
- **Pricing:** paid (closed API; open-sourcing promised in team comments)
- **Platform:** API
- **Local-friendly:** no (API only for now)
- **Availability:** limited (paid API only)
- **Last reviewed:** 2026-08-30

## What it does
A fine-tune of the open-source MiniMax H3 that posts both the best quality score and the lowest average latency in Stability's comparison table, generating within seconds.

## When to use it
If you need MiniMax-quality video at API speed and don't mind paying. Otherwise FastVideo for MiniMax covers the same speed problem in the open; note the sour taste of an open model being optimized and paywalled, with open-sourcing only promised.
