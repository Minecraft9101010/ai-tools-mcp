# MultiWorld

Open-source video world generation framework that creates multi-agent, multi-camera-angle game and robot environments simultaneously.

## What it does
MultiWorld generates video game or robotics environments with multiple agents (characters/robots) interacting in a scene, captured from multiple camera angles simultaneously. Uses an agent identity embedding system to keep each agent distinct and a global state encoder for multi-view consistency. Can generate diverse game environments (multiplayer games) and two-robot manipulation scenes from different perspectives. Particularly useful for generating synthetic training data for multi-agent robotics.

## When to use it
Generating synthetic multi-agent training data for robotics. Creating consistent multi-camera game environment videos. Simulation and world model research where you need coherent multi-agent scenes without a physics engine.
