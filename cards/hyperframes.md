# Hyperframes

Open-source framework for creating animations with code, in the same niche as Remotion.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (code-based animation package)
- **Availability:** available
- **Last reviewed:** 2026-06-17

## What it does
Lets an agent or developer build video animations programmatically. In the video, GLM 5.2 was pointed at the GitHub repo cold and figured out installation and usage itself to produce a finished 16:9 promo video with synced voiceover and background music.

## When to use it
Programmatic video production driven by a coding agent, as an alternative to Remotion. Useful when you want the agent to own the whole pipeline from product page to rendered promo.
