# Fire Red Image Edit

Open-source semantic image editor with strong face and outfit consistency.

- **URL:** https://huggingface.co/ (search "Fire Red Image Edit")
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no — base model is ~60GB; GGUF/quantized versions expected soon
- **Availability:** available
- **Last reviewed:** 2026-03-13

## What it does
Edits images via text prompts while preserving face, identity, and outfit consistency across changes. Handles background changes, pose changes, outfit swaps, makeup addition, multi-reference image merging, and custom typography/font application. Version 1.1 beats competing open-source editors including Quint Image Edit and Long Cat Image Edit, and surpasses Nano Banana Pro on some benchmarks.

## When to use it
Creative image editing where you need to preserve subject identity — product shots, character consistency across multiple images, adding visual style from reference photos, and text style application.
