# OpenAI Codex App

Desktop app for agentic coding with GPT models, allowing multiple parallel agents to work on a project folder.

- **URL:** https://openai.com/codex (downloadable)
- **Pricing:** free to download; uses your ChatGPT plan credits
- **Platform:** desktop app
- **Local-friendly:** no (calls OpenAI API)
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Organizes coding projects into folders, each treated as a separate workspace. You can run one or multiple AI agents simultaneously on the same project, iterate continuously, and open results in a browser preview. More effective than the ChatGPT web interface for building complex apps.

## When to use it
Use when vibe-coding or building multi-file projects with GPT-5.5. The folder-based structure keeps context organized and lets the agent handle full builds without copy-pasting code back and forth.
