## What it does
Translates live audio while also reading visual context from the screen or video feed, using both signals to improve accuracy. Supports 60 languages. A free demo is available.

## When to use it
Translating live streams or video calls where on-screen text, slides, or visual context would help the model produce more accurate translations than audio-only approaches.
