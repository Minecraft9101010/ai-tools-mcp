# Kimi K3 (Moonshot AI)

Open-sourced 2.8T-parameter model that was the best open model at release and matches or beats GPT-5.6 / Fable 5 on some benchmarks.

- **Availability:** available

## What it does
Massive open-sourced frontier-class model from Moonshot AI (released ~late July 2026). Tops the open-model field on the Artificial Analysis leaderboard, one point above Qwen 3.8 Max, and reaches closed-frontier performance on several benchmarks.

## When to use it
Highest-intelligence open-weights option when you can pay API rates or run datacenter hardware; pair it with Kimi Code, its first-party harness. Qwen 3.8 Max is the close, slightly cheaper-to-host rival.
