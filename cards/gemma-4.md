# Gemma 4

Google's open-source multimodal model family that runs on consumer hardware, including phones and edge devices.

- **URL:** https://ai.google.dev/gemma
- **Pricing:** open-source
- **Platform:** local | API | web
- **Local-friendly:** yes — 2B and 4B variants run on phones/Raspberry Pi; 24B and 31B run on consumer GPUs
- **Availability:** available
- **Last reviewed:** 2026-04-05

## What it does
Four model sizes (2B, 4B, 24B, 31B) that handle text, images, and audio natively in one model. Apache 2.0 licensed. Trained on 140+ languages. Context windows of 128K (small models) and 256K (large models). The 24B is a mixture-of-experts model with only 3.8B active parameters at runtime.

## When to use it
When you need a capable open model for local or on-device deployment, especially for multilingual tasks, real-time audio/vision, or embedding AI into edge hardware without cloud dependency.
