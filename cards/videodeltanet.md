# VideoDeltaNet

VideoDeltaNet speeds up Minimax H3 video generation by replacing expensive attention with a hybrid attention system.

- **URL:** https://openvdn.github.io/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says the model and code are released with local run instructions.
- **Availability:** available
- **Last reviewed:** 2026-09-06

## What it does
It reduces runtime while preserving video quality, with VDN-H3 producing speedups over full Minimax H3. It also has ComfyUI support through a custom node.

## When to use it
Use it when you want faster local Minimax H3 video generation with less quality loss than other speedup methods.
