# Pixel3D

Single image to high-fidelity 3D mesh generator.

- **URL:** not mentioned
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no (24GB total VRAM, mid-to-high GPU required)
- **Availability:** available
- **Last reviewed:** 2026-05-17

## What it does
Converts a single reference image into a 3D mesh using a pixel-aligned approach. Benchmarks show it outperforms Trellis 2 and Hunyuan3D on fidelity. Requires 24GB total.

## When to use it
Game assets, product visualization, and virtual production when you have a reference photo and need a high-quality 3D mesh.
