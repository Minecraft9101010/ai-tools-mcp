# DeepSeek Harness

DeepSeek's first official agentic harness/scaffold for its own models, replacing reliance on third-party frameworks like Hermes or Open Claw.

- **URL:** not mentioned (GitHub, developer preview)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (a scaffold/orchestration layer, not a model)
- **Availability:** limited (developer preview, actively iterating with breaking changes expected)
- **Last reviewed:** 2026-08-16

## What it does
An official orchestration framework for running DeepSeek models agentically — analogous to Claude Code for Claude or Codex for GPT — after DeepSeek previously had no first-party harness and users relied on third-party options like Hermes or Open Claw.

## When to use it
Running DeepSeek models (like V4 Pro) agentically if you want the harness built by the same team as the model, accepting that it's an early, fast-moving developer preview.
