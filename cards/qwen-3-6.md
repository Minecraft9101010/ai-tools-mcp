# Qwen 3.6 (35B A3B)

Alibaba's open-source 35B mixture-of-experts model with only 3B active parameters — efficient and strong on agentic and coding tasks.

- **Availability:** available

## What it does
Mixture-of-experts model with 35B total parameters and 3B active at inference. Outperforms other similar-sized models on average, especially autonomous coding, agentic tasks, Terminal Bench, SWE Bench Pro, graduate-level reasoning, competitive math, and multimodal image reasoning. Compatible with Claude Code, Open Claw, and Qwen Code.

## When to use it
Open-source alternative to frontier closed models for agentic workflows. Try via chat.qwen.ai for free before committing to local setup.
