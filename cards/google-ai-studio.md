# Google AI Studio

Google's developer platform for accessing and testing the Gemini API.

- **URL:** aistudio.google.com
- **Pricing:** freemium
- **Platform:** web | API
- **Local-friendly:** no (cloud-based)
- **Availability:** available
- **Last reviewed:** 2026-05-21

## What it does
Provides direct access to Gemini models for prompt testing and API-based deployment. Primary entry point for developers integrating Gemini into their own products.

## When to use it
Integrating Gemini via API, testing prompts before production, or getting direct model access without a consumer-facing wrapper.
