# UnifoLM

An open-source robot model for converting robot observations, instructions, and state into actions across many tasks.

- **URL:** https://unigen-x.github.io/unifolm-wla.github.io/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says the model is under 9 GB and could fit locally/offline in a robot
- **Availability:** available
- **Last reviewed:** 2026-09-13

## What it does
UnifoLM takes what a robot sees, user instructions, and robot state to generate correct robot actions. The video says it supports 64 tasks across tabletop manipulation and whole-body coordination.

## When to use it
Use it for robotics research requiring a compact open model for manipulation, whole-body coordination, and multi-task robot control.
