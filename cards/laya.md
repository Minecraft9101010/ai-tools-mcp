# Laya

An open-source system-one model for scoring multiple-choice decisions.

- **URL:** https://laya.convaiinnovations.com/
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes - open-source Apache 2 model with GitHub install instructions
- **Availability:** available
- **Last reviewed:** 2026-09-20

## What it does
Laya accepts a prompt and a set of possible answers, then outputs confidence scores. The video describes it as similar to Jev, multilingual, fast, and small enough for consumer devices.

## When to use it
Use it when you want a local open-source alternative to Jev for structured decision scoring.
