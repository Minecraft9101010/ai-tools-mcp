# Gemini 3.1 Flash TTS

Google's most expressive text-to-speech model, supporting emotion meta-tags and over 70 languages.

- **URL:** https://aistudio.google.com
- **Pricing:** freemium (free in AI Studio; API usage billed)
- **Platform:** web | API
- **Local-friendly:** no
- **Availability:** available
- **Last reviewed:** 2026-06-01

## What it does
Generates highly natural speech with fine-grained control via emotion meta-tags embedded in the prompt (e.g., excited, whispers, panicked, sighs, laughs). Supports pacing control with dramatic pauses. Outperforms ElevenLabs v3 in expressiveness comparisons. Supports 70+ languages. No voice cloning — uses preset speakers with various accent options.

## When to use it
Generating expressive narration, character voices, or podcast-style audio when you need emotional range and pacing control. Available free in Google AI Studio. Not suitable if you need voice cloning of a specific person.
