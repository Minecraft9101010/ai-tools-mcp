## What it does
Accepts normal text prompts or detailed JSON prompts with fields for description, location, relative size, shape and color, texture, and more, following the structured spec closely. Also edits existing images with natural language, iteratively — add a blanket, then books, then a cat, across successive prompts.

## When to use it
Programmatic or pipeline image generation where structured, field-level control beats prose prompting. Not the top raw-quality generator; pick it for the JSON interface and iterative editing rather than for best-in-class output.
