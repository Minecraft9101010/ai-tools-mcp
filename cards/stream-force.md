# Stream Force

Video generator controlled by physical forces: push, pull, or blow objects in a scene with a force signal instead of a text prompt.

## What it does
Generates video where motion is dictated by applied forces you can change over time, like a physics joystick. Supports global forces (wind affecting the whole scene) and local forces (moving one chair or one apple). Causal and streaming, so it reacts in real time as you change the force signal; the page claims up to 16.6 fps on a single CPU.

## When to use it
Interactive video generation where you need direct, continuous control over object motion rather than describing it in a prompt. Watch for the code release.
