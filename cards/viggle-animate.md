# Viggle Animate

Viggle Animate swaps or animates a character in a video using a single edited reference frame.

- **URL:** https://huggingface.co/Viggle/Viggle-Animate
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says the models are released with download and run instructions.
- **Availability:** available
- **Last reviewed:** 2026-09-06

## What it does
It transfers motion from an original video character onto a new character without pose estimation, segmentation, or face tracking. It is a fine-tune of Minimax H3 and includes both a full fine-tune and a smaller LoRA.

## When to use it
Use it to replace or animate characters in existing clips across different proportions and art styles.
