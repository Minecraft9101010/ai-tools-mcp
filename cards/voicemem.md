# VoiceMem

Real-time memory system for voice agents — remembers facts and feelings about the user across conversations with sub-second latency.

## What it does
Splits memory into a "left brain" (facts: people, entities, knowledge) and a "right brain" (preferences, personality, emotions). Instead of stuffing old conversations back into context, it searches a memory graph and fetches only the few memories that matter — beating competitor methods on memory accuracy while using far fewer tokens, at sub-second latency.

## When to use it
Building personalized voice assistants or companion agents where recall of past conversations is the product — the efficiency and latency profile is designed specifically for real-time voice, unlike general LLM memory layers.
