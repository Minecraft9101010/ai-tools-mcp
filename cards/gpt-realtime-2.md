# GPT Realtime 2 (OpenAI)

OpenAI's latest generation of real-time voice models: conversational voice, live speech translation (70+ languages), and real-time transcription.

- **URL:** https://platform.openai.com
- **Pricing:** paid (API only; per-model pricing)
- **Platform:** API
- **Local-friendly:** no (cloud API only)
- **Availability:** available
- **Last reviewed:** 2026-05-10

## What it does
Three models released together: (1) GPT Realtime 2 — conversational voice agent with enhanced reasoning and more natural speech; significant improvement over v1.5 across audio benchmarks. (2) GPT Realtime Translate — live speech translation across 70+ input languages to 13 output languages, translates while you're still speaking. (3) GPT Realtime Whisper — real-time speech-to-text transcription for captions or meeting notes. All API-only at launch.

## When to use it
Building voice-based companion apps, customer support agents, or multilingual meeting tools. GPT Realtime Translate is the standout for live interpretation use cases where natural turn-taking matters. Whisper variant for automated captioning or transcription pipelines.
