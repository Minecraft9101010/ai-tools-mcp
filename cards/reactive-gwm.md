# Reactive GWM

Open-source AI game world model for generating interactive video game simulations with text-steerable NPC behavior.

- **URL:** not mentioned (GitHub)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes (mid to high-end GPUs)
- **Availability:** available
- **Last reviewed:** 2026-05-24

## What it does
Generates interactive video game simulations where NPC behavior can be steered via text prompts. Built on Wan 2.2. Produces playable-style game environments rather than static video output.

## When to use it
Game AI research, prototyping controllable NPC behavior, or building interactive simulations where text-based steering of agents is the goal.
