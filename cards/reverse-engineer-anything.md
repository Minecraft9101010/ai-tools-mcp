# Reverse Engineer Anything

A GitHub repository of ready-made skills and MCPs for AI-assisted reverse engineering workflows.

## What it does
Reverse Engineer Anything provides ready-made tools, skills, and MCPs that AI agents can connect to for reverse engineering tasks. The video presents it as an alternative or complement to Universal Modder.

## When to use it
Use it when you want to give an AI agent reverse-engineering capabilities for game analysis, rewriting, or modding workflows.
