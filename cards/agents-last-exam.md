## What it does
Gives agents long, multi-step, domain-specific workflows with clear outcomes instead of isolated questions: animation and VFX work, 3D modeling, medical software analysis, architectural modeling, game development, and more. As of June 2026 the leaderboard has GPT-5.5 Codex on top, beating Claude Fable 5 (which frequently gates or silently degrades answers), followed by GPT-5.5, Open Claw, and Cursor's Composer.

## When to use it
Choosing an agent model for real professional work rather than toy coding tasks, or evaluating your own agent harness against realistic job-shaped workflows. Runnable yourself from the GitHub repo.
