# Deepseek V4 Flash Vision Experimental

Deepseek V4 Flash Vision Experimental is Deepseek's vision-capable flash model released on Hugging Face.

- **URL:** https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp/tree/main
- **Pricing:** open-source
- **Platform:** local, API
- **Local-friendly:** yes, the transcript says it can be downloaded and run locally for free, though it is about 168 GB.
- **Availability:** available
- **Last reviewed:** 2026-09-06

## What it does
It adds vision capabilities to Deepseek's V4 Flash line and is described as competitive with frontier vision models. It was first available via API and then open-sourced on Hugging Face.

## When to use it
Use it for local or API-based multimodal tasks when you need a vision-capable Deepseek model and have enough hardware.
