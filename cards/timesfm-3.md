# TimesFM 3

TimesFM 3 is Google Research's open-source zero-shot foundation model for multivariate time-series forecasting.

- **URL:** https://research.google/blog/timesfm-3-a-zero-shot-foundation-model-for-multivariate-forecasting
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** yes, the transcript says it can be downloaded, run locally, and is small enough for most consumer devices.
- **Availability:** available
- **Last reviewed:** 2026-09-06

## What it does
It predicts future numerical time-series data across domains like retail, healthcare, weather, and finance. It is a 330M-parameter model trained on over a trillion time points and can forecast without task-specific retraining.

## When to use it
Use it for forecasting related signals when you want a small local model and do not want to retrain for each new dataset.
