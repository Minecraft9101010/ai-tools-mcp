# ChatGPT Dreaming (Memory Update)

ChatGPT feature that synthesizes memory from past conversations in the background so responses stay current instead of relying on stale saved notes.

- **URL:** https://chatgpt.com
- **Pricing:** freemium (rolling out to free users; paid users get expanded memory capacity)
- **Platform:** web | mobile | desktop app
- **Local-friendly:** no (cloud feature)
- **Availability:** limited (rolling out over the coming weeks as of this review)
- **Last reviewed:** 2026-06-07

## What it does
Instead of only pulling from explicitly saved memory notes (which can go stale — e.g. still assuming you're on a trip that already ended), ChatGPT now synthesizes context from past conversations in the background to keep its understanding of your preferences and situation current. OpenAI reports meaningful gains in task correctness and factual recall as things change over time.

## When to use it
Ongoing ChatGPT use where context should carry forward accurately across sessions without manual memory management — trip planning, evolving projects, personal preferences.
