# Qwen VideoEdit

Edits existing videos with text prompts by running Qwen Image Edit frame by frame through a Wan video generation workflow.

- **URL:** not mentioned (code and training script released)
- **Pricing:** open-source
- **Platform:** local
- **Local-friendly:** no (total size ~41GB; needs a high-end GPU)
- **Availability:** available
- **Last reviewed:** 2026-08-23

## What it does
Not a new video model: it plugs the existing Qwen Image Edit editor into Alibaba's Wan video pipeline so natural-language edits apply consistently across a whole video. Training script included.

## When to use it
Text-driven edits to existing footage if you're already in the Qwen/Wan ecosystem. MiniMax H3 can already edit existing videos, so this mostly matters as an open, hackable pipeline rather than a better result.
